## 这是什么

AI 工具越强，企业越不敢用 —— 成本黑盒、过程黑盒、质量黑盒，三黑盒叠加就是**信任缺口**。
ContextJemo（产品线名 **Rhea**）做的是企业 AI 的**信任基础设施**：无论 Agent 跑在哪个平台，
接入即纳入同一套审计、门禁、成本管控与记忆沉淀。

- **门禁分级** — G1 需求评审 → G7 结项验收，每关审核深度可调（auto / agent / human），不通过不往下走
- **全链路审计** — 时间线 + 因果链，可像看监控一样回放每一步决策
- **成本显性化** — 模型无关、可路由，每一分钱花在哪张图的哪条边上都看得见
- **记忆资产化** — 团队经验沉淀为可跨团队订阅的资产，用得越久越懂你
