## 这是什么

ContextJemo 解决的是**「打法留不住」**：一个团队反复调出来的好 prompt、好流程、好判据，散在聊天记录和个人习惯里，换个人就归零。

ContextJemo 把这些打法变成**文件**——

- **AET 战术文件**（`.aet.yaml`）：声明式编排。人能审、Agent 能跑、git 能 diff。
- **内核 MD**：角色的判断依据与执行契约。
- **判据与证据**：跑完留下可查的结果，而不是一次性的对话记录。

## 开源边界

**我们不整仓开源。开放的是格式，完整的是运行。**

| 层 | 内容 | 许可 / 交付 |
|---|---|---|
| **开放层** | AET 规范与 schema、解析与校验器、并行耦合 lint、官方模板库、Kernel MD / SKILL.md 格式说明、共享类型契约、白皮书 | **Apache-2.0**，独立仓库发布 |
| **完整版** | 编排执行与调度、门禁 G1–G7 与判据、审计时间线与证据链、记忆与交接、成本路由与多模型适配、Studio / Teams 前端、许可与运维 | **商业授权 / 私有化交付** |

**为什么**：格式层开放才有人接得上——复制的前提是别人能解析你的文件；执行层是一体的，拆开单卖只会把完整版降格成零件商。

**开放层什么时候发布**：AET 规范 v1.0 已冻结，但**尚未独立开源**。独立开源的触发条件写在 spec §六，是条款不是形容词：

| 触发条件 | 当前 | 目标 |
|---|---|---|
| 实战时间 | 0 天 | ≥ 3 个月生产使用 |
| 战术数量 | 5 | ≥ 20（含外部贡献） |
| 第二实现解析器 | 0 | ≥ 1（任意语言 / 团队） |
| 外部作者 | 0 | ≥ 3 |
| Schema 稳定 | v0.3 频繁改 | v1.0 锁定 + ≥6 个月无 breaking |

任一满足即发布独立仓（`SPEC.md` / `schema/` / `examples/` / `CHANGELOG.md` / `LICENSE` / `README.md`）。
